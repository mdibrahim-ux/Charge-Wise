How the planner works

Usable full-charge range = manufacturer IDC range × riding condition factor. Projected SOC consumption = road distance / usable range × 100. Reserve is applied to each leg. Compatible stops are shortlisted by proximity, then checked with routed legs when routing is available. The prototype supports up to two charging stops; it reports when no safe route can be found.

Estimated charging time uses the vehicle battery capacity, conservative effective input power, and an allowance for losses/taper. It is not an operator quote. Times exclude queueing and live traffic. The road profile is a car-routing approximation, not a scooter-specific routing service.

For custom places, Nominatim geocoding is restricted to a Bengaluru bounding box. This box is approximate, not a legal city boundary. OpenFreeMap provides vector maps; a configured OSRM service provides road routes; Overpass returns community-mapped locations. All third-party services may be unavailable or rate limited. Local fallback estimates are not directions.

Privacy: notes, imported stations and theme are stored in this browser. Location queries and route coordinates are sent to the public mapping services only when required. No account or tracking service is included.
